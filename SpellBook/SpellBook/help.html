Introduction

Welcome to SpellBook, a comprehensive tool for fringe detection and analysis. This software is designed to assist in processing interferograms, allowing users to detect fringes and manually refine masks for accurate plasma density calculations.

The application is divided into two main workflows: Detection and Editor.

Detection Tab

The Detection tab is the starting point for processing raw interferograms. It uses image processing algorithms to illuminate the image, enhance contrast, and automatically trace fringes.

Key Features

  • Illumination & Enhancement: Automatically adjusts image lighting to highlight fringe patterns.
  • Auto-Tracing: Detects fringe lines based on configurable parameters.
  • Live Preview: See changes in real-time as you adjust sliders.

Controls

  • Navigation: Right-click drag to pan, Mouse wheel to zoom.
  • Blur σ: Controls the Gaussian blur sigma. Higher values smooth out noise but may blur fine details.
  • Line Length & Thickness: Defines the expected dimensions of fringes to be detected.
  • Max Angle & Step: Configures the orientation sensitivity of the detection algorithm.
  • Morphology Operations:
    • Dilate: Thickens detected lines.
    • Min Area: Removes small noise artifacts.
    • Prune Spurs: Removes small branches from the skeletonized fringes.
    • Fill Loops: Closes small holes within fringes.
  • Hump Width: Flattens fringes by removing "humps" or irregularities. Set to 0 to disable.
  • Background Opacity: Adjusts the visibility of the original image behind the detected fringes.

Editor Tab

The Editor tab provides a powerful environment for manual refinement. Here you can clean up the automatically detected fringes, add missing sections, and create gray masks for specific regions.

Tools & Modes

  • Image Loading: Use Load Shot Image and Load Ref Image to place original context images behind your masks. Use Open Shot Binary / Open Reference Binary to load masks.
  • Alignment & Cropping:
    • Nudge: Use arrow keys to nudge the reference image and its mask by 1 pixel.
    • Reset Nudge: Realigns images to their initial positions.
    • Crop View: Draw a rectangle to crop the view (max 2048x2048). Use Reset Crop to undo.
  • Brush Modes & Drawing:
    • Add/Remove Black: Freehand draw or erase binary fringe lines.
    • Draw Line (1px): Click and drag to draw straight lines.
    • Draw Spline (1px): Left-click to add points to a curve, Ctrl+Left-click to finish and draw the spline.
    • Add/Remove Mask (Gray): Paint a gray mask to exclude regions from analysis.
  • Brush Control: Hold Ctrl and scroll the mouse wheel to adjust the brush size dynamically.
  • Ruler: Measure pixel distances. Use the Lock dropdown to constrain measurement to Horizontal or Vertical.
  • Link Endpoints: Automatically connects nearby open endpoints of fringes based on distance and angle tolerances.
  • Magic2 Line: Draws an invisible vertical line; fringes touching this line are highlighted.
  • Color Comps: Toggles random coloring of connected components to easily identify separate fringe segments.
  • Merge Binaries: Load another binary image to overlay on top of your current work, then combine them.

Shortcuts

  • Undo: Ctrl + Z or use the Undo button.
  • Zoom/Pan: Mouse wheel to zoom, Right-click drag to pan.
  • Nudge: Arrow keys.
